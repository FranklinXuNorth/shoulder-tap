# shoulder-tap：敲屏幕提醒

## 产品动作

一只手从屏幕侧边伸进来，用指关节轻敲三下，再收回去。像有人拍一下你的肩膀。
手势是统一的介入信号，不按提醒内容画喝水、走路、完成、放行或猫角色。
原先六组像素素材需求由本说明取代。

只有两类提醒，共用同一个动作：

1. **偏离计划**：当前请求与正在做的任务无关。模型暂停执行，说明当前任务，等用户决定回去做还是改计划。
2. **该做某事了**：用户自己设定的提醒到点。文字来自用户的规则，动画不识别习惯类别，也不代表用户做错了。

不因完成任务或检查通过播放动画。习惯提醒本身不应强制锁住工作。

## 第一版交互

打开 [敲屏幕原型](../skill/shoulder-tap/ui/index.html)。

- Tab 或「敲一下」触发：伸手 → 轻敲三下 → 收手。约 1.7 秒，不循环。
- Tab 仅在原型画布获得焦点时作为演示按键；输入框和其他控件保持正常键盘行为。Shift+Tab 离开画布。
- 两类提醒只换文字，使用同一只手和动画；内容可自定义。
- 动画结束后文字保留，Escape 或关闭按钮收起；连续触发不堆叠。
- overlay 其余区域不拦截点击，不夺取焦点。减少动态效果设置下静态出现。
- 第一版无声音，先验证视觉节奏。

## 绘制方向

只有一只手和少量前臂，手指弯曲成轻松的敲门姿势，指关节朝向屏幕。
不要张开手掌拍打，不要握紧拳头砸屏幕。伸入、敲击和收回应一眼读懂。
透明背景，轮廓清楚，浅色和深色桌面都可辨认；肤色配青色袖口，敲击处少量短线即可。
原型使用 SVG 手和 CSS 动画，尚不是最终美术素材。

## 接入边界

原型只是浏览器视窗内的 overlay，不是系统级桌面悬浮窗，没有注册全局 Tab 热键。
后续桌面容器接收统一事件 `{ kind: 'off-task' | 'due', message: string }`，共用敲击动画。
偏离计划事件由模型语义判断产生；到期事件由用户配置的规则产生。
