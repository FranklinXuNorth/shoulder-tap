本地与跨机器：一次拍肩怎么走

2026-09-24 这次更新之后的全貌。三只手（拍拍、taptap、响指）都走同一条路： 先看本机是不是你在用的那台，是就直接拍；不是才经 Cloudflare 送到那台。 行为契约看 behavior，跨机器的取舍看 cross-machine。

机器 A 和机器 B 是同一份代码，只是谁发起、谁被盯着的角色不同。本机就是活跃的那台时（最常见）， 整条路都不出机器：钩子 → 常驻进程 → 屏幕，150 毫秒上下；常驻进程随后把这一下补记进频道历史。
