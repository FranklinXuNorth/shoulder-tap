shoulder-tap 数据流

你今天说好要做的事存在你自己的 Notion 里。Vercel 上那台服务只是一段通路： 它拿着你随请求带来的 token，去读写你自己的库，返回一段给模型看的判断规则，然后什么都不留。 这页把每一跳都画出来。

01 — 拓扑

数据只在三个地方待过

左边是你的电脑，右边是你的 Notion，中间那台服务器两头都碰得到，但两头的东西它都不保留。

02 — 主回路

一次 check_focus 的完整往返

你说「帮我改一下落地页的配色」，在模型动手之前发生的事：

  1. 模型决定先查一下
    Claude Code · 依据 ~/.claude/CLAUDE.md 里那几行
    把你要做的事原样塞进 activity。这一步是规则驱动的，不是服务端能强制的——所以那几行必须粘到全局 CLAUDE.md 里。
  2. 发请求
    local → vercel
    POST /api/mcp
Authorization: Bearer ntn_••••••••          ← 你的 Notion 密钥
X-Shoulder-Tap-Key: ••••                    ← 可选门禁

{"method":"tools/call","params":{
  "name":"check_focus",
  "arguments":{"activity":"改落地页配色"}}}

    withMcpAuth · 见下一节
    门禁头对不上、或者 token 不是 ntn_ / secret_ 开头 → 直接 401，连 Notion 都不会碰。

03 — 判断

三条分支，规则写死在返回里

模型拿到的不是一句「请自行判断」，而是三条带动作的指令。拿不准时默认走最严的那条。

A 放行 就是当前这条

直接干活，一个字都不要提这次检查。但不会替你勾掉——只有你明确说这条完成了，模型才调 complete_focus；它至多问一句「这条算完成了吗」。

B 顺序不对 在清单里，但靠后

不动手。提醒你前面还有一条没做完，问你是先做完那条，还是真要改顺序（那就 set_focus 重排）。等你回答。

C 拦下 压根不在清单里

不动手，也不做任何一步。点破你在偏离，复述当前那条，问你：这是必须插队的急事（add_focus），还是你该回去做那条？等你回答。

模型可以被说服，这是故意的。 你说一句「无视，这个更急」，它就放你过去。这东西是为了让你想起来，不是为了锁住你—— 真要锁，你下次就不装它了。

04 — 核查

一个请求要过几关

01 门禁头 X-Shoulder-Tap-Key只在你设了 SHOULDER_TAP_KEY 时才检查。防的是路人蹭额度，跟数据无关。 401
02 Bearer 前缀是不是 ntn_ / secret_拦掉明显不是 Notion 密钥的东西，省一次外部请求。真假由 Notion 判。 401
03 缺了必需的 scopemcp-handler 按 RFC 9728 回 WWW-Authenticate 挑战。 403
04 Notion 认不认这个 token假密钥在这里现原形：API token is invalid。 unauthorized
05 搜不到那个库要么没建过，要么页面没在 ⋯ → Connections 里连上 integration。返回会直接告诉模型去调 setup。 not_set_up

05 — 谁看得见什么

经过 Vercel 的东西，一样不落

东西存在哪Vercel 看得到吗落盘吗
Notion 密钥你电脑上的 ~/.claude.json看得到（每次请求都带）不落盘
今天的任务你的 Notion看得到（读出来拼文本）不落盘
你说的那句 activity没有存看得到（拼进返回）不落盘
习惯和上次时间你的 Notion看得到不落盘
token → 库 id 的缓存函数实例内存看得到实例回收即消失
对话内容你的电脑看不到从不经过
诚实的说法是这样：数据不在我这儿存着，但请求经过我这儿的那一瞬间，进程内存里确实有你的 token 和你今天的任务—— 任何中转都绕不开这一点。想彻底绕开，就自己 fork 一份部署到你自己的账号下，代码全在这儿。

06 — 副回路

身体上的提醒走同一趟车

不额外开定时器，也不弹系统通知。每次 check_focus 顺手算一遍：now − Last > EveryMinutes 的挂在返回末尾，让模型在正常回答的最后轻轻带一句。

工具做什么落到 Notion 的哪
check_focus拦路 + 顺带报超时的习惯只读
set_focus按顺序重设今天，旧的进回收站Shoulder Tap
add_focus插一条，可插队，后面顺延Shoulder Tap
complete_focus勾掉或放弃第 N 条Shoulder Tap
log_habit你说喝了，才把计时清零Shoulder Tap Habits
setup第一次建两个库 + 三条默认习惯你指定的页面下
模型只在你跟它说话的时候才知道现在几点。 所以提醒永远是「你刚才开口时，顺便说一句」，不是「到点了弹你一下」。 要真的到点弹窗，得靠本地那层——那是另一条路，还没修。
