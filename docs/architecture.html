shoulder-tap 架构

全部跑在你自己的机器上。事情怎么一步步走，看 flow。

你的所有习惯 + 要做的事情的数据不上云。 shoulder-tap 没有服务器。数据要么在这台机器的一个 JSON 文件里，要么在你自己的 Notion 里（这台机器直接连）。

每一块做什么

部件在哪做什么
mcp.mjsskill 目录本机 stdio MCP。check_focus、set_focus、add_focus、complete_focus、add_habit、log_habit、stop_habit、habit_history、setup。协议手写，没有依赖
watch.mjsskill 目录，挂在 Claude Code 的四个钩子上你开口时把今天的清单塞进模型上下文（读缓存，不等网络）；模型说完一轮时看结尾有哪只手就拍哪下；模型弹问题时打响指
onboard.mjs + ui/app.htmlskill 目录托盘 / 菜单栏点一下打开的那一页。打开时先显示响指的手；数据、图、字体都就绪并画出来之后再停 0.5 秒，打一下响指，渐入。第一次是五步引导加一步「试一下」；之后是首页：「重新走一遍设置」「选择皮肤」两个入口，下面是最近两周的待办、在盯的习惯和习惯历史。只监听 127.0.0.1，只认同源请求，页面半小时没动静自己退出
core/store.mjsskill 目录选后端：config.json 里的 storage。local.mjs 和 focus.mjs（Notion）是同一套函数
shoulder-tap-tap~/.claude/shoulder-tap/app屏幕右缘那只手：一轮做完打响指，模型问你话拍拍你，跑偏或习惯到点 taptap。Windows 托盘 / macOS 菜单栏常驻，开机自启

文件都在哪

文件里面是什么
~/.claude/shoulder-tap/data.json本地存储时的任务和习惯（习惯一次一行，含历史）。时间一律存 UTC，「今天」读的时候按时区现算
~/.claude/shoulder-tap/config.jsonstorage（local / notion）、onboarded
~/.claude/shoulder-tap/state.json钩子的缓存：上一次 check_focus 的整段返回
~/.claude/skills/shoulder-tap/.envNotion 密钥（选了 Notion 才有）、可选的 Jev 密钥

数据长什么样（Notion）

一个库「Shoulder Tap」，靠 Kind 区分两种行。本地 data.json 是同一个模型。

字段类型task 行habit 行
Nametitle步骤本身习惯名
Kindselecttaskhabit
IDrich_textt-a3f91ch-8b12d4
Ordernumber第几条—
Statusselectpending / done / droppedpending = 当前激活；done = 做了；dropped = 跳过或停用
Daydate哪一天（UTC，读时按时区换算）这一次被激活的时刻（UTC）
TZrich_text写这行时的时区同左，At 按它算
EveryMinutesnumber—隔多久一次（和 At 二选一）
Atrich_text—每天几点，HH:MM
Lastdate—这一次做完（或跳过）的时刻
Typeselect—soft（简单随手，不能跳过）/ hard（看情况，可以说今天不做）
Noterich_text执行细节备注，跳过的原因也写这

习惯一次一行：做了 → 这行 done，生成下一行 pending；跳过 → 这行 dropped，下一行从明天算；停用 → 这行 dropped，不再生成。 历史 = Kind = habit 且 Status ≠ pending。已有的库会被接管，只补缺的字段；老库里没有 Status 的习惯行当作激活中。

可选：本机直连 Jev

.env 里填 JEV_API_KEY（JEV_BASE_URL 默认 https://api.typesafe.ai），watch.mjs 会在你开口时直接从本机请求 Jev 做首轮「相不相关」比较； 不填就由对话模型自己判。2 秒超时，超了静默退回。SHOULDER_TAP_LOCAL_JEV=0 临时关掉。只发两行字，不碰其它数据。
