# shoulder-tap 桌面端

一只手从屏幕右缘伸进来，用食指点三下，然后收回去。1.7 秒，全程没有一个字。

**屏幕上不显示文字，这是故意的。** 要说的话已经在聊天里了，再弹一遍只是让你多读一次；
而一张需要读、需要关的卡片，本身就是第二次打断。手只负责让你抬头。

网页原型在 [`../skill/shoulder-tap/ui/index.html`](../skill/shoulder-tap/ui/index.html)，
这里是它的桌面版：WPF，手的路径和那三段动画的时间轴是从原型里原样搬过来的。

## 对外只有一条命令

```bash
shoulder-tap-tap.exe --text "先停一下。你说好要整理 JD。"
```

| 参数 | |
| --- | --- |
| `--text` | 这次拍肩是为了什么。**不上屏**，只落进托盘提示，留个事后能看一眼的地方。没有它就只是把进程拉起来常驻，不拍。 |
| `--quit` | 让常驻进程退出。 |

**调用方不需要判断 App 在不在。** 没开就开起来然后拍，开着就直接拍——
互斥量负责回答「有没有人在跑」，命名管道负责把这次要说的话交过去。

**这条命令永远立刻返回**，冷热两条路都是 0.2 秒上下。这一点不是附带的：
调用方常常是一个在等退出码的 shell，让它挂在那里等一个常驻进程退出，
就是把提醒工具变成了卡死工具。所以命令行那一端从不自己常驻——
它派一个带 `--daemon` 的自己出去，然后退场。`--daemon` 是内部暗号，你不用写。

派进程时走 `UseShellExecute`，起来的进程不继承父进程的句柄，
否则调用方的 shell 会因为管道还开着而接着傻等，等于没修。

万一上一个进程还占着互斥量却已经聋了，交不出去的那次会派个新的出去顶上；
新的拿不到互斥量就自己拍一次再退。提醒不会被一次意外吞掉。

## 窗口是什么样的

一层铺满工作区的透明覆盖层，内容贴右缘。四条硬性要求，少一条它就从提醒变成骚扰：

- **不抢焦点**：`ShowActivated=False` 加 `WS_EX_NOACTIVATE`。你正在打字的那个窗口不会失去输入。
- **鼠标穿透**：`WS_EX_TRANSPARENT`。挡在上面也点得到底下的东西。
- **不进任务栏和 Alt+Tab**：`ShowInTaskbar=False` 加 `WS_EX_TOOLWINDOW`。
- **拍在你正在看的那块屏上**：取前台窗口所在的显示器，不是主显示器，也不是鼠标所在的——
  鼠标经常忘在别的屏上。

手收回去时只 `Hide()`，进程留着，所以只有第一次有冷启动。深浅色跟随系统。
系统关了动画（`ClientAreaAnimation`）就不演，让手静静地出现一下再消失。

托盘图标是它唯一看得见自己还活着的地方，也是唯一能关掉它的地方——
一个无窗口、不进任务栏的常驻进程，否则只能去任务管理器杀。

## 两个坑，都踩过了

**句柄要先造出来。** `PlaceOnActiveScreen` 如果跑在 `Show()` 之前，`SetWindowPos` 打在空句柄上
会静默失败，窗口就停在 WPF 的默认位置和大小，右半边溢出屏幕。构造函数里 `EnsureHandle()` 解决。

**跨显示器要摆两次。** 两块屏缩放不同时，第一次 `SetWindowPos` 会同步触发 `WM_DPICHANGED`，
尺寸被按**旧** DPI 换算掉（150% → 100% 时 1920 缩成 1280）。等 DPI 切换完再摆一次才算数。

## 编译和安装

需要 .NET 10 SDK。装到哨兵放状态的那个目录下，`watch.mjs` 默认去那儿找：

```bash
dotnet publish desktop -c Release -o "$HOME/.claude/shoulder-tap/app"
```

大约 210 KB，框架依赖，不含运行时。换个位置的话用 `SHOULDER_TAP_APP` 指过去。

**没装也不影响任何事。** `watch.mjs` 找不到 exe 就安静跳过，纯文本的拍肩照常工作。

## 谁会调它

只有 `watch.mjs`。模型从不自己调这个 exe——拍肩这件事不该由被拍的人自觉，
漏读一行 CLAUDE.md 就哑掉的提醒等于没有提醒。哨兵在两个时刻替它去拍：

- **`PostToolUse`**：习惯到期的时候。那是真正的推送，你没开口，也没人在等你回话。
- **`Stop`**：模型说完一轮，结尾有那只 ASCII 手就拍。钩子的输入里直接带
  `last_assistant_message`，不用去解析 transcript。
  这一路还会带上 `--caption`，一小条字贴在手旁边：拍拍（做完了）放这轮回答的第一句，
  taptap（跑偏/习惯）放手后面那句提醒。手敲完停两秒，字条和手一起淡出。字条是屏幕上唯一的字，所以刻意短（80 字封顶）。


只看消息**结尾** 800 个字符，锚点是食指那一笔 `________/)`。
中间引用到那段 ASCII（比如正在改这个仓库）不算数，否则改这里会被自己拍一路。
锚点刻意挑了不含反斜杠的一段：反斜杠在字符串里多一层少一层都不报错，只会安静地匹配不上。

`Stop` 不为子 agent 触发（那是 `SubagentStop`），所以后台任务不会拍你一脸。
